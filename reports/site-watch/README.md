# Site-watch reports

Generated by `python3 scripts/site-watch/watch.py`.

| File | Meaning |
| --- | --- |
| `YYYY-MM-DD.md` | Dated weekday (or ad-hoc) run, UTC date in the filename. |
| `SAMPLE.md` | Checked-in example from a real run so reviewers can see the shape without executing. |

These files are HTTP observations only. They are not CRM notes and they are
not a license to publish or change phone numbers. See
[`scripts/site-watch/README.md`](../../scripts/site-watch/README.md) for the
phone lock.
